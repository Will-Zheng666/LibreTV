# 电视答题守卫 · 使用说明

> 版本 v2.6 · 适配雷鸟/TCL 85 寸（Android 9 / 1920×1080）

---

## 一、它做什么

孩子打开视频 App 累计看满 **15 分钟** →

1. **视频自动暂停**
2. **全屏黑底遮罩弹出一道四年级题目**
3. 遥控器只能答题，按别的键都没用
4. **答对** → 遮罩消失，视频继续，重新计时
5. **答错** → 补一道（最多补 2 道）
6. 答不出来就一直挡着

## 三、日常使用

### 启动

从「我的应用」打开**一次**即可，之后常驻，重启电视也会自动起来。

不需要每次点「启动守卫」。

### 操作方式

遥控器**方向键上下**移动高亮框 → **OK** 确认。没有触摸屏。

### 家长豁免（来客人、看春晚时）

```
① 打开「电视答题守卫」
② 方向键走到「⑦ 家长豁免 2 小时（需家长密码）」
③ 按 OK
④ 弹九宫格 → 方向键选 1 → 2 → 3 → 4
⑤ 状态变「家长豁免：剩余 120 分钟」
```

**豁免期间**：不弹题，但**仍然计时**（日报能看到）。
**2 小时后**自动恢复。
**提前结束**：同样走 ⑦ 那个对话框，点「取消豁免」。

### 看日报

主界面下方直接显示，**不需要密码**：

```
今日报告
今天已看：47 分钟
答题轮次：4 轮（补题 2 道）
按应用：
  影视仓  25 分钟
  野火直播  12 分钟
```

## 四、哪些操作要密码

**设计原则：看数据随便看，削弱守卫必须输密码。**

| 按钮 | 要密码 | 说明 |
|---|---|---|
| ① 授予悬浮窗权限 | 否 | 无害 |
| ② 无障碍设置 | 否 | 关掉后 5 秒自动恢复 |
| ③ 启动守卫 | 否 | 只会加强 |
| ④ 提醒间隔 | **是** | 防孩子改成 30 分钟 |
| ⑤ 立即弹一次 | 否 | 自找麻烦，无害 |
| ⑥ 停止守卫 | **是** | 核心保护 |
| ⑦ 家长豁免 2 小时 | **是** | 核心保护 |
| 看今日报告 | 否 | 孩子看了也没用 |

密码：**1234**（九宫格方向键输入，不需要数字键）

## 五、以后要改东西，不用重装 APK

页面从磁盘加载，改完 `adb push` 就生效。

### 改题目 / 改样式

**位置**：`/sdcard/Android/data/com.family.tvguard/files/quiz.html`

```bash
adb push quiz.html /sdcard/Android/data/com.family.tvguard/files/quiz.html
```

**必须保留** `<!--QG-QUIZ-OK-->` 这行标记，没有它会被当成损坏文件、自动回退内置版本。

### 改题库

**位置**：`/sdcard/Android/data/com.family.tvguard/files/quiz-data.js`

```bash
adb push quiz-data.js /sdcard/Android/data/com.family.tvguard/files/quiz-data.js
```

### 改提醒间隔 / 黑名单

**位置**：`/sdcard/Android/data/com.family.tvguard/files/config.json`

```json
{
  "thresholdSec": 900,
  "blockSettings": true,
  "debug": true,
  "watchPkgs": [
    "com.audiovisual.live",
    "com.cibn.tv",
    "com.cm.live",
    "com.github.itvbox.ruyitv",
    "com.huawei.himovceie",
    "com.newtv.cboxtv",
    "com.today.player",
    "com.wtj.cn.alipantv",
    "yhzb.player.plus"
  ]
}
```

**thresholdSec 换算**：

| 想要 | 填 |
|---|---|
| 10 分钟 | 600 |
| 15 分钟 | 900 |
| 20 分钟 | 1200 |
| 30 分钟 | 1800 |

改完 `adb push config.json ...`，**20 秒内自动生效**。

## 六、调试命令（只有电脑能发）

```bash
PKG=com.family.tvguard

# 立即弹一次（验布局）
adb shell am start -n $PKG/.MainActivity --ez force_quiz true

# 看日志（视口尺寸、焦点序号、答题结果）
adb logcat -s QG

# 清零今天的数据
adb shell am broadcast -a $PKG.RESET

# 手动测自愈：清空无障碍，13 秒后应自动写回
adb shell settings put secure enabled_accessibility_services ""
sleep 13
adb shell settings get secure enabled_accessibility_services
```

## 七、已知限制

| 限制 | 说明 |
|---|---|
| 首次装完要打开一次 App | Android 8+ 禁止后台启动前台服务，只能在 App 前台时拉起 |
| 电视待机可能杀进程 | 无 root 无法彻底解决；日报里能看到时长断层 |
| 遥控器没有数字键 | PIN 用九宫格方向键输入 |
| 投屏/HDMI 不计时 | 看投屏内容不会弹题 |
| 主界面「提醒间隔」显示可能滞后 | 实际以 config.json 的 thresholdSec 为准 |

## 八、无障碍被关了怎么办

**不用管** —— 有自愈机制：

```
每 5 秒检查一次 → 发现被关 → 自动写回
同时保留：Aerial 桌面守护、小T助手
```

前提权限（已通过 adb 授予，覆盖升级后保留）：

```bash
adb shell pm grant com.family.tvguard android.permission.WRITE_SECURE_SETTINGS
```

## 十、故障自检

| 现象 | 检查 |
|---|---|
| 不弹题 | 主界面看「无障碍计时」是不是 ✓；看「今日报告」时长有没有在涨 |
| 弹出来是空的 | 外部 quiz.html 缺 `QG-QUIZ-OK` 标记，或 quiz-data.js 没推 |
| 选项被切掉 | 不该发生；如出现，删掉外部 quiz.html 让它回退内置版 |
| 孩子关掉无障碍 | 等 5 秒自己恢复；或主界面看「无障碍计时」是否变 ✓ |
